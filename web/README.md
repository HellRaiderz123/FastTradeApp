# FastTrade Web

Modern algorithmic trading platform built with React + TypeScript.

## Installation

```bash
npm install
```

## Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Build

```bash
npm run build
```

## Features

- 📊 Real-time dashboard with portfolio metrics
- 🎯 Strategy generator with signal analysis
- 📈 Position tracking and management
- 📋 Trade journal with analytics
- ⚙️ Advanced settings configuration
- 🔒 Risk management controls
- 📱 Responsive design
- 🌙 Dark mode (default)
